# NeonGuitarLab

Gitarren-Übe-App für das Solospiel mit einzelnen Tönen: Tempo und Technik, Orientierung auf dem Griffbrett und das Vokabular dafür.

- Speedtrainer: Laufband mit Bursts, langsamen Passagen, Selbstbewertung und Statistik
- Griffbrett: Tonerkennung über das Mikrofon, vier Stufen, Stimmgerät
- Vokabular: fünf Pentatonik-Positionen in drei Tonarten, Arpeggios, Licks, Hören und Nachspielen

Die App ist eine einzelne Seite (`index.html`) und läuft über GitHub Pages aus dem Zweig `gh-pages`. Auf dem Handy lässt sie sich über das Browser-Menü als App installieren.

Die Seite lädt nichts von fremden Servern. Die Schriften im Ordner `fonts` (Bricolage Grotesque, IBM Plex Mono, Tilt Neon) stehen unter der SIL Open Font License 1.1.
