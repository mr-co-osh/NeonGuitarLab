# NeonGuitarLab

Gitarren-Übe-App.

- Speedtrainer: Laufband mit Bursts, langsamen Passagen, Selbstbewertung und Statistik
- Griffbrett: Tonerkennung über das Mikrofon, Stufen 1 bis 3, Stimmgerät

Die App ist eine einzelne Seite (`index.html`) und läuft über GitHub Pages aus dem Zweig `gh-pages`. Auf dem Handy lässt sie sich über das Browser-Menü als App installieren.
